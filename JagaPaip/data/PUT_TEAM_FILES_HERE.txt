The app reads the team's files from the repository automatically:
- data/data/   Member 1 tables (pipe_year, features, outcomes, breaks_clean, pipes_clean)
- data/        Member 1 manifest.json
- artifacts/   fold_predictions.parquet (Contract B), metrics.json, ranked_worklists.parquet (Contract C)

Files dropped into this folder take precedence over the repository copies.
Leave it empty for the demo so the app always shows the current team results.

If no pipe_year file is found anywhere, the app falls back to a labelled synthetic demo.
City of Kitchener data does not establish effectiveness for Malaysian utilities.
